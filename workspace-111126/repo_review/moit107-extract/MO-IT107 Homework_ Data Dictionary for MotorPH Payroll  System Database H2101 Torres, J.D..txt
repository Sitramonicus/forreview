        Listed below are the key terms and acronyms used throughout this document.

                    Taxpayer Identification Number – a unique number assigned to individuals or entities for tax

                    Social Security System Number – an identifier used to track social security contributions and
SSS                 benefits.

                    Identifier for the Philippine Health Insurance Corporation – used to manage health insurance
PhilHealth          records and contributions.

                    Identifier for the Pag-IBIG Fund (Home Development Mutual Fund) – used for housing
PagIbig             savings and related benefits.

                    Paid Time Off – the policy allowing employees to take leave while still receiving their regular
PTO                 pay.

                    No, not Archimedes' constant. Abbreviation used in rate fields (piEmployerRate,
PI                  piEmployeeRate, piMaxContribution) – refers to Pag-IBIG related contribution rates.

                    A shortened identifier used in logging to represent specific table and column names concisely
fieldCode           (e.g., "P_NP" for Payroll.NetPay).

Varchar             Variable Character – a data type for storing text strings of varying lengths.

Varbinary           Variable Binary – a data type for storing binary data that does not have a fixed length.

Enum                Enumeration – a data type that defines a set of predefined values.

TinyInt             Tiny Integer – a data type representing a small-range integer (values that typically won’t

                      reach beyond 127)

                      Small Integer – a numeric data type used to store integers within a limited range (values that

                      The total number of digits allowed in a decimal number, both to the left and right of the
