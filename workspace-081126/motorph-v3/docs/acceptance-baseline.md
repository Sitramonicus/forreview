# Source-grounded acceptance baseline (draft)

**Purpose:** record observable pass/fail behavior already implemented and define safe candidate acceptance criteria before tailoring. This is a working baseline, **not an approved rubric interpretation**. No standalone active MO-IT110 grading rubric was identified among the supplied files in the workspace; the older MO-IT108/107 documents and peer submissions inform scope, while the Terminal Assessment proposal is treated as placeholder material rather than an authoritative detailed specification.

**Scope rules:** fictional data only; use the signed-in user's sandbox in Firebase mode; keep ordinary local-preview persistence explicitly process-memory; do not treat inferred attendance/payroll rules, peer-project choices, employee-to-account identity, reviewer authority, or access boundaries as approved policy. At the user's direction, a clearly labelled 2026 monthly statutory preview is now available with synthetic inputs only; its rules are isolated in a changeable module and it has no API/Firestore/payslip path. Attendance-based or persistent payroll, approvals, and reviewer controls remain gated. See `docs/candidate-policy-review.md`. The user-published development rules remain unchanged.
